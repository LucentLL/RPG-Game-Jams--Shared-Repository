Does Chrome pick raster scale from LAYOUT size or from the EFFECTIVE transform?

All three rows paint the same picture at the same on-screen size (900×180 CSS px).
A is authored at 900px with no ancestor scale. B and C are authored at 300px with scale3d(3) on the ancestor — the K-scale.
If B and C look identical to A, raster scale follows the effective transform: the K-scale allocates the same texture and buys nothing.
If B and C look soft / blocky, raster scale follows layout size: the K-scale is a real 9× memory cut.
